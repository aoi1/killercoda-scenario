# ターミナルをもう1つ開く

シナリオ②では、ターミナルを2つ使います。ここで練習しておきましょう。

## やること1：Tab 2を開く

ターミナルの上にあるタブの「**+**」を押して、2つ目のターミナル（Tab 2）を開いてください。

## やること2：Podの様子を流しっぱなしにする

**Tab 2** を開いた状態で、下のコマンドをクリックしてください。

```
kubectl get pods -w
```{{exec}}

`-w` は「変化があるたびに表示する」オプションです。コマンドが終わらずに、待ち続ける状態になります。

このまま「Check」を押してみましょう。各ステップの最後にある「Check」ボタンは、手順どおりにできているかを確認するボタンです。

<details><summary>ヒント：Checkが通らないときは</summary>

- Tab 2で `kubectl get pods -w` が動いたままになっているか確認してください
- `Ctrl + C` で止めてしまった場合は、もう一度コマンドをクリックしてください

</details>

## やること3：止める

Checkが通ったら、Tab 2で `Ctrl + C` を押して、コマンドを止めてください。`Ctrl + C` は「実行中のコマンドを止める」操作です。
