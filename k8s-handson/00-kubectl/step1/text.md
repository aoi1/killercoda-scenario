# コマンドを実行してみる

この手順にあるコマンドは、**クリックするだけ**で右のターミナルで実行されます。自分で入力する必要はありません。

## やること

下のコマンドをクリックしてみましょう。

```
kubectl version
```{{exec}}

ターミナルに `Client Version` と `Server Version` が表示されましたか？

- **Client**：いま使っている `kubectl` コマンドのバージョン
- **Server**：kubectlが話しかけているKubernetes（**クラスタ**）のバージョン

kubectlは、Kubernetesに「これを見せて」「これを作って」とお願いするためのコマンドです。

<details><summary>ヒント：クリックしても何も起きないときは</summary>

ターミナルの準備がまだ終わっていないかもしれません。右側に「準備ができました！」と表示されているか確認してください。

</details>

確認できたら「Next」を押して次に進みましょう。
