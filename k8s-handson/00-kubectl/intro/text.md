# ⓪ kubectlを使ってみる

このハンズオンでは、Kubernetesにアプリをデプロイして、わざと**こわして**みます。

| シナリオ | やること |
|---|---|
| **⓪（いまここ）** | **kubectlを使ってみる** |
| ① | Podをこわす |
| ② | Deploymentをこわす |
| ③ | Serviceをこわす |

こわしはじめる前に、まずはこの環境とKubernetesを操作するコマンド **kubectl**（キューブシーティーエル）に慣れておきましょう。

## 画面の見方

- 左側（いま読んでいるところ）が**手順**です
- 右側の黒い画面が**ターミナル**です。ここでコマンドを実行します

## 準備

右側のターミナルに「準備ができました！」と表示されるまで待ってから、「START」を押してください。
